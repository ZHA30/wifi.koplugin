# wifi.koplugin

Kindle Wi-Fi management for KOReader.

> [!NOTE]
> This plugin targets Kindle Paperwhite (11th Generation), firmware 5.17.1.0.3.

## Features

- Scan nearby networks, connect to saved or new networks, change passwords, and forget networks using Kindle system services. Networks are grouped into known and other networks, with the current connection shown first.

- Menu: `Network` -> `Wi-Fi management`. Requires Wi-Fi to be enabled.
